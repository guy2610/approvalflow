ApprovalFlow

An asynchronous invoice approval workflow where an AI agent can recommend, but deterministic policy, autonomy limits, and human review remain authoritative.

Open interactive demo View repository View v1.0.0
The browser demo is a static portfolio simulation. The complete implementation, including the services and persistence layer, runs locally through Docker Compose.

What the project demonstrates

Reliability and safety mechanisms around an agent-assisted business workflow.

Deterministic guardrails

Policy configuration, confidence thresholds, category rules, and cumulative autonomy budgets control the final route.

Human in the loop

Approvers can approve, reject, or request information. Updated submissions return for revision-aware policy evaluation.

Reliable workflow behavior

Idempotency, optimistic concurrency, stale-event rejection, compensation, audit records, and durable local state.

Asynchronous architecture

Go services communicate through Dapr invocation and pub/sub, backed by Redis and PostgreSQL.

Operational visibility

Correlation IDs, structured logs, audit trails, notifications, analytics, health checks, and an operations runbook.

Evaluation and deployment assets

Automated verification, race testing, OpenAPI documentation, CI, Docker images, and Kubernetes reference manifests.

Workflow

The static demo presents the same main workflow scenario as the complete implementation.

1. Submit
2. Agent recommends
3. Policy decides
4. Human reviews
5. Pay / compensate
6. Audit
